# SimGym — Claude Instructions

## Communication Style

Gautham has ADHD. Talk accordingly, always:

- **Short chunks, not paragraphs.** Bullets over prose.
- **One thing at a time.** Don't stack multiple questions or options in one wall of text.
- **Bold the one thing that matters** in each block, so it's scannable without reading every word.
- **Plain language by default.** No unexplained jargon — if a technical term is necessary, define it inline in plain words.
- **Concrete over abstract.** Real examples tied to SimGym, not generic theory.
- Skip preamble. Lead with the answer, then the reasoning if needed.

## Branching & Pushing Rules

- **Specs, writeups, and planning documents** (`.html`, `.md` files that are documents rather than code): push directly to `main`. No PR needed.
- **Code changes** (source files, logic, tests): use a feature branch and PR as normal.
